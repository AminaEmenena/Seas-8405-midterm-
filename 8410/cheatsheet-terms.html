1. Visualization & Charts

Bar chart: compares categories, bars have GAPS between them

Histogram: shows distribution of ONE numeric variable, bars TOUCH

Scatter plot: shows relationship between TWO variables

Line chart: shows trends over TIME

Pie chart: shows parts of a whole, angle = relative frequency x 360, HARD TO READ

Heatmap: shows values in a matrix using color intensity

Word cloud: bigger word = more frequent

Data-ink ratio: maximize data, minimize chart junk (Tufte)

Pre-attentive attributes: color, size, orientation, shape -- brain processes before conscious thought

Perception hierarchy: position > length > angle > area > color

Dashboard: "visual display of most important info on single screen, monitored at a glance" (Stephen Few)

Expressiveness: viz shows ALL and ONLY the facts (Mackinlay)

Effectiveness: info is readily perceived (Mackinlay)

Top-left corner: most important info goes here (eye starts there)

13 anti-patterns: exceed screen, no context, too much detail, wrong measure, wrong viz type, meaningless variety, bad design, inaccurate encoding (Y-axis!), poor arrangement, bad highlighting, clutter, color misuse, ugly

2. Data Types & Sampling

Nominal: labels with NO order (eye color, IP address, port number)

Ordinal: labels WITH order (low/med/high, satisfaction scale)

Interval: numbers, no true zero (temperature C/F, dates)

Ratio: numbers, true zero (height, weight, age, packet size)

NOIR: Nominal < Ordinal < Interval < Ratio (increasing info)

Port number: NOMINAL not ratio (arithmetic meaningless)

Temperature C/F: INTERVAL not ratio (0 degrees is not "nothing")

Simple random sampling: every unit has equal chance

Stratified: sample a BIT from EVERY group

Cluster: sample WHOLE groups (everything from a few)

Systematic: every m-th item after random start

Population: everything. Sample: slice you measure

Descriptive stats: summarize data you have (mean, charts)

Inferential stats: generalize from sample to population (hypothesis tests)

3. Center, Spread & Shape

Mean: average, sensitive to outliers

Median: middle value, ROBUST to outliers, use for skewed data

Mode: most frequent, only center measure for nominal data

"Mean chases the tail": right-skew = mean > median, left-skew = mean < median

Range: max minus min

Variance: average of squared deviations from mean, use n-1 for sample

Standard deviation: square root of variance, back in original units

Z-score: (value - mean) / SD, how many SDs from mean, unitless

Empirical Rule: 68-95-99.7% within 1-2-3 SDs, BELL-SHAPED ONLY

Chebyshev: at least 1-1/k^2 within k SDs, works for ANY shape

Correlation r: measures LINEAR relationship, range [-1, +1], NOT causation

Parameter: population measure (Greek: mu, sigma)

Statistic: sample measure (Latin: X-bar, S)

4. Data Preprocessing

Garbage in, garbage out: bad data = bad results

Step Zero: EXPLORE data first (df.describe(), data dictionary)

df.dropna(): remove rows with missing values

df.fillna(): fill missing values with specified value

df.drop_duplicates(): remove duplicate rows

Imputation: filling missing data (mean/median/mode, ffill, bfill, KNN, model-based)

Feature engineering: create NEW features from existing data, "secret sauce"

Normalization: scale features so none dominates

Endpoint: any device on network (laptop, phone, server, IoT)

Outlier: value far from rest, wrecks mean but not median

5. Hypothesis Testing

H0 (null): boring default, always has = sign, like "innocent"

H1 (alternative): your claim, has inequality

NEVER say "accept H0" -- say "fail to reject"

Type I error (alpha): false alarm, reject true H0

Type II error (beta): missed detection, keep false H0

Power: 1 - beta, ability to catch real effect

Alpha: chosen BEFORE looking at data

p-value: probability of data this extreme IF H0 is true

p < alpha: reject H0. p >= alpha: fail to reject

Z-test: Z = (X-bar - mu0) / (sigma / sqrt(n))

Standard error: sigma / sqrt(n), shrinks with larger n

One-tailed: rejection region in one tail. Two-tailed: both tails

Two-sided p-value: DOUBLE the one-tail probability

10. Regression & Classification

Linear regression: Y = b0 + b1*X + error, straight line through scatter

b0 (intercept): Y when X = 0

b1 (slope): change in Y per 1-unit increase in X (the important number)

Least squares: minimizes squared vertical distances (residuals)

Gauss-Markov: least squares = best unbiased linear fit

Always scatter plot FIRST before fitting

Logistic regression: S-curve (sigmoid), predicts probability [0,1] for yes/no

Cutoff: probability threshold for "yes" (default 0.5, adjustable)

Lower cutoff = catch more but more false alarms

Confusion matrix: 2x2 of predicted vs actual (TP, TN, FP, FN)

Sensitivity: of real YES, how many caught? TP / (TP + FN)

Specificity: of real NO, how many cleared? TN / (TN + FP)

Accuracy alone is misleading: 99% normal data -> lazy model 99% accurate, 0% sensitivity

ROC curve: sensitivity vs (1-specificity) across all cutoffs

AUC: 0.5 = coin flip (BAD), 1.0 = perfect

11. ANOVA & Advanced Tests

ANOVA: compare means of 3+ groups (extends t-test)

F-statistic: between-group variance / within-group variance

Large F: groups differ more than random noise explains

Why not multiple t-tests: inflates false positive rate (~14% for 3 groups)

ANOVA assumptions: independence, normality, equal variance

Tukey post-hoc: which specific groups differ (after ANOVA rejects)

Two-way ANOVA: 2 factors + INTERACTION (read interaction row FIRST)

Interaction: effect of one factor DEPENDS on level of other

MANOVA: multiple correlated response variables at once

Kruskal-Wallis: non-parametric alternative to one-way ANOVA

Friedman: non-parametric alternative to two-way ANOVA

Sign test: tests median, count plus/minus signs, Binomial(n, 0.5)

Security data is often non-normal: skewed, heavy-tailed, zero-inflated, ordinal

13. Outlier Detection

IQR: Q3 - Q1 (width of middle 50%)

Mild outlier: past Q1 - 1.5*IQR or Q3 + 1.5*IQR

Extreme outlier: past Q1 - 3*IQR or Q3 + 3*IQR

Mean is fragile (outliers drag it), median is robust

In security: outlier might BE the attack -- investigate before deleting

Boxplot: visual outlier detector built from quartiles

Decision tree: flowchart classifier (root -> internal nodes -> leaves)

Overfitting: tree too deep memorizes noise, fix with pruning
