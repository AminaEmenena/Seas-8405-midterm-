Study Tip: This course bridges data science and cybersecurity. Focus on understanding what data to collect for each security domain, how to preprocess it, and which visualization best tells the story. Know the dashboard anti-patterns (Stephen Few) and Gestalt principles cold. The professor emphasized: "Whatever we covered in class, you should know it." Tool capabilities (Power BI, Splunk, Tableau, Python) are fair game as concepts.
Week 1 -- Visualization Fundamentals Perception + Chart Types-->
How visuals are perceived, guidelines for leveraging perception, common visualization types (bar charts, scatter plots, line charts, pie charts, histograms), and the power of color in data presentation.
Week 2 -- Data Sources & Visualization Tools Tools + Storytelling-->
Data sources and storage technologies. Hands-on with Excel, Power BI, Python (matplotlib, seaborn, pandas), Tableau, and Splunk. "Getting the Visualization Done" and telling the data story.
Week 3 -- Endpoint Security Visualizations Preprocessing + ML Pipeline-->
Endpoints defined. Data preprocessing pipeline: exploration, cleaning (dropna, fillna, duplicates), feature engineering, imputation methods (mean/median/mode, KNN, model-based, forward/backward fill), outlier detection (z-scores, box plots, df.loc).
Week 4 -- User Security Data Visualizations DBIR + Privacy Laws-->
What is a "user" (human and non-human). Verizon DBIR findings (60% human element, credential abuse 22%, vuln exploitation 20%). User security data sources. Privacy laws: GDPR, CCPA, PIPEDA, LGPD, DPA 2018.
Week 5 -- Code Security Data Visualizations Breaches + Secure Coding-->
Heartbleed (CVE-2014-0160), Equifax breach (CVE-2017-5638), XZ Utils backdoor (CVE-2024-3094), CrowdStrike outage (Channel File 291). Von Neumann architecture. CVE/NIST. 10 steps to secure code. SAST vs DAST.
Week 6 -- App Security, Dashboards & Outlier Detection Stephen Few + Mackinlay-->
Application security defined. Dashboard design (Stephen Few): expressiveness & effectiveness (Mackinlay criterion). 13 dashboard anti-patterns. Choosing the right visualization type.
Week 7 -- Log Security & Gestalt Principles Log Types + Visual Perception-->
What is a log. Log types: system, application, network, security, audit, web server, database. Gestalt 6 principles of visual perception: proximity, similarity, closure, continuity, enclosure, connection.
Week 8 -- Cloud Security, Parametric vs Non-parametric Tests Sign Test + Cloud Viz-->
Scaling visualization with cloud security analytics. Parametric tests (Z-test, assume normal, test mean) vs non-parametric tests (sign test, distribution-free, test median). When to use each. The sign test mechanics: count plus/minus signs around claimed median, compare to binomial.
MEGA REVIEW -- All Topics Quiz 80 Questions-->
Comprehensive quiz covering all 8 weeks. Test your knowledge on visualization fundamentals, security domains, data preprocessing, dashboard design, log analysis, and cloud security analytics.
