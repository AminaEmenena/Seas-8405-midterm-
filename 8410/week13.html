🎨 1. Visualization Fundamentals (W1)
HISTORY: Dr. John Snow's 1849 cholera map is considered one of the earliest and most famous examples of data visualization for problem-solving -- he mapped cholera deaths in London to trace the outbreak to a contaminated water pump.

Chart Types for Single Dimensions

  • Pie charts -- proportions of a whole (use sparingly, hard to compare)
  • Bar charts -- comparing categories (horizontal or vertical)
  • Line charts -- trends over time
  • 3D bar charts -- adding a third dimension (can distort perception)
Simple charts for single dimensions. Start simple, add complexity only when the data demands it.

What's Behind Pivots (W2)

Dragging and dropping = measures across dimensions. When you pivot data, you are mapping measures (Risk, values) across dimensions (Country, Reliability). Understanding this concept is key to building effective dashboards.
🔎 3. Data Exploration & Preprocessing (W3)
STEP ZERO = EXPLORE DATA FIRST. Before any analysis, understand what you have: data dictionary, df.describe(), CSV loading, basic profiling.

Exploration Essentials

  • Data dictionary -- know what each field means
  • df.describe() -- summary statistics at a glance
  • CSV loading -- most common data interchange format
  • Big data technologies: Hadoop, Kafka, Spark
  • Python with open-source databases -- flexible and cost-effective

Data Preprocessing

GARBAGE IN, GARBAGE OUT. No visualization or model can compensate for dirty data.
  • Cleaning -- handle missing values, duplicates, outliers
  • Imputation -- fill missing values strategically
    • Forward fill -- carry last known value forward (good for time-series)
    • Backward fill -- use next known value (good for time-series)
  • Feature engineering -- create new meaningful variables from existing data
💻 4. Endpoint Security (W3)
DEFINITION: An endpoint is any device communicating with the network -- desktops, laptops, servers, smartphones, tablets, IoT devices. These are primary attack targets.

Security Measures

  • Firewalls -- control network traffic in/out
  • Antivirus -- detect and remove malware
  • IDS/IPS -- Intrusion Detection/Prevention Systems
