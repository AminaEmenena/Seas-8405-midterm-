📈 3. Parametric vs Non-Parametric Tests -- Core Difference
KEY DISTINCTION: Parametric tests assume data follows a known distribution (usually normal/bell curve). Non-parametric tests make almost no assumptions about data shape -- also called "distribution-free."

Comparison Table

FeatureParametricNon-Parametric
Assumes distribution?Yes (normal)No
Works on what data?Numeric, bell-shapedAny shape, ordinal is fine
Based on?Means, standard deviationsOrder/ranks/signs
Power when assumptions hold?HigherSlightly lower
Robust to outliers?NoYes
ExampleZ-test, t-test (mean)Sign test (median)

How to Choose

Decision rule: Is data roughly bell-shaped and numeric? If yes, use parametric (more power). If data is skewed, has heavy outliers, or is only ordinal (rankings, ratings), use non-parametric. You trade a little power for not pretending your data is normal when it's not.
The Z-test from Week 5 is parametric. It assumes a normal distribution.

Non-Parametric Tests Still Have Assumptions!

  • Variable is continuous
  • Measured on at least ordinal scale (you can rank values)
  • They just don't assume a specific distribution shape
➕ 4. The Sign Test -- Simplest Non-Parametric Test
DEFINITION: The Sign Test checks a claim about the MEDIAN (not mean!) by counting how many data points fall above vs below a hypothesized value.

Setup

Sample from continuous distribution with unknown median M. Want to test if M equals some value m0.

Hypotheses (mirror Week 4 but about median)

TypeH0H1
Left-sidedM = m0M < m0
Right-sidedM = m0M > m0
Two-sidedM = m0M != m0

Why It's Called the SIGN Test

Subtract m0 from each data point and look only at the sign. Above m0 gets a plus (+), below gets a minus (-).

How It Runs

  1. Step 1: For each Xi, record 1 if Xi - m0 > 0 (plus), 0 if negative (minus). If any value equals m0 exactly, discard it and shrink n
  2. Step 2: Test statistic R = count of plus signs
  3. Step 3: Under H0, R follows a Binomial distribution with p = 1/2 (coin-flip). Too few or too many pluses (depending on tail) means reject H0
Intuition: If true median is m0, about half should be above and half below (50/50 coin flip). If way off from half, the median is probably not m0.

Security Relevance

Security data is often skewed (login times, packet sizes, dwell times have heavy tails). Non-parametric tests let you test claims without pretending the data is normal.

Memory Aid "Sign test = MEDIAN test = coin flip (p=0.5)" -- count the pluses, compare to what a fair coin would give
🚫 5. Exam Traps -- Don't Fall For These
COMMON MISTAKES:
  • Saying non-parametric tests have NO assumptions -- they still need continuous, at-least-ordinal data
  • Thinking the sign test is about the mean -- it's about the MEDIAN
  • Forgetting to discard values exactly equal to m0 and adjust n
  • Using a parametric test on clearly non-normal data just out of habit
  • Confusing "distribution-free" with "assumption-free" -- non-parametric still has assumptions, just fewer
REMEMBER: Under H0, the sign test statistic R ~ Binomial(n, 0.5). It's literally a coin-flip model.
