W1 - Visualization Fundamentals
  • CHARTS: Bar (categories, GAPS), Histogram (distribution, bars TOUCH), Scatter (2 vars, correlation), Line (time trends), Pie (AVOID - angle=rel.freq*360, 25%=90deg). Heatmap (matrix, color intensity). Stem-and-leaf (preserves digits).
  • PERCEPTION: Position > Length > Angle > Area > Color. Use position-based (bar) over area-based (pie).
  • PRE-ATTENTIVE: Color, size, orientation, shape - processed <200ms before conscious thought. Max ~4 distinct features.
  • DATA-INK RATIO (Tufte): = Data-ink / Total ink. MAXIMIZE data ink, MINIMIZE chart junk. Remove gridlines, 3D, decoration.
  • COLOR: Sequential (low-to-high, one hue), Diverging (center point, two hues), Categorical (distinct groups, max ~7). ~8% males colorblind (red-green).

W3 - Endpoints, Preprocessing & Measures
  • ENDPOINT: Any device on network (desktop, laptop, server, IoT). ML pipeline: clean->feature eng->train->score->evaluate. Garbage in garbage out. Data prep = 80% of work.
  • CLEANING: df.describe() df.dropna() df.fillna() df.drop_duplicates() df.loc[mask]. Imputation: mean/median/mode (simple), ffill/bfill (time-series), KNN (preserves relationships, O(n^2)), model-based (best accuracy).
  • FEATURE ENGINEERING: Create NEW features from existing = "secret sauce" of ML. Requires domain knowledge.
  • CENTER: Mean (sensitive to outliers), Median (robust, rank=(n+1)/2), Mode (nominal data only). Shape: mean=median=mode symmetric. "Mean chases the tail" - right-skew: mean>median>mode.
  • SPREAD: Range=max-min. Variance S^2=sum(Xi-Xbar)^2/(n-1) [n-1 sample, N population]. SD=sqrt(S^2) back to original units.
  • PARAMETER (Greek: mu, sigma) vs STATISTIC (Latin: Xbar, S).
  • EMPIRICAL: 68-95-99.7% within 1-2-3 SD (bell ONLY). Chebyshev: ANY shape, at least 1-1/k^2 (k=2: 75%, k=3: 88.9%).
  • Z-SCORE: Z=(Xi-mean)/SD, unitless. |Z|>3 = outlier. Correlation r: r=Cov/(Sx*Sy), [-1,+1], NOT causation, LINEAR only.
W4 - User Security & Hypothesis Testing
  • USER: Human OR non-human with ID + permissions. DBIR 2025: 60% human element, 22% credential abuse, 53% system intrusion, internal 10x more records. 30% third-party.
  • PRIVACY: GDPR (EU, consent, 72hr notification, 4% revenue fine), CCPA (CA, know/delete/opt-out), PIPEDA (Canada), LGPD (Brazil), DPA 2018 (UK).
  • H0 = null (always has = sign). H1 = alternative (inequality). Never "accept H0" -- "fail to reject."
  • ERRORS: Type I = alpha = false alarm (reject true H0). Type II = beta = missed detection. Power = 1-beta. Bigger samples reduce BOTH.
  • 6 STEPS: 1) State H0/H1. 2) Pick alpha BEFORE data. 3) Choose test statistic. 4) ID distribution. 5) Find rejection region. 6) Compute and decide.
  • TAILS: H1 decides WHERE rejection region. Alpha decides HOW BIG. One-tail (H1: < or >), Two-tail (H1: !=, alpha/2 each side).
W5 - Code Security & Hypothesis Mechanics
  • CODE SECURITY = CIA. Von Neumann: CPU+Memory+I/O, shared memory = injection attacks possible.
  • CVEs: Heartbleed (2014, bounds check, 64KB leak). Equifax (2017, unpatched 6mo, 147M). XZ Utils (2024, 3yr social engineering, supply chain). CrowdStrike Ch291 (8.5M BSOD, NOT hack, SQA=security).
  • SAST = static, white-box, no execution, early dev. DAST = dynamic, black-box, app running, runtime. No scans -> no production.
  • Z-TEST: Z=(Xbar-mu0)/(sigma/sqrt(n)). SE=sigma/sqrt(n). Bigger n -> smaller SE -> more convincing.
  • P-VALUE: P(data this extreme | H0 true). p<alpha -> reject. Two-sided: p=2*P(Z>=|z|). P-value is NOT P(H0 is true).
W6 - Dashboards & Outlier Detection

W7 - Log Analysis & Gestalt Principles
  • LOG: Chronological record of events. Types: system, application, network, security, audit, web server, database. Essential for forensics, compliance, anomaly detection.
  • GESTALT 6 PRINCIPLES: Proximity (near=grouped), Similarity (alike=grouped), Closure (brain completes incomplete shapes), Continuity (follow smooth paths), Enclosure (STRONGEST - bounded region=group), Connection (linked=grouped).
  • STRENGTH ORDER: Enclosure > Connection > Proximity/Similarity. Use enclosure (borders, shading) for most important groupings in dashboards.
W8 - Parametric vs Non-Parametric & Decision Trees
  • PARAMETRIC: Assume normal distribution, test mean, Z-test/t-test. Use when bell-shaped data, large n, continuous ratio/interval.
  • NON-PARAMETRIC: Distribution-free, test median, sign test. Use when skewed, ordinal, outliers, small n, non-normal.
  • SIGN TEST: H0: M=m0. Compare each value to m0, count pluses (+) and minuses (-). Discard ties. R=number of pluses ~ Binomial(n, 0.5). Use binomial table for p-value.
  • DECISION RULE: Bell-shaped -> parametric. Skewed/ordinal/outliers/small n -> non-parametric.
  • DECISION TREES: Root node (top), internal nodes (splits), leaf nodes (predictions), branches (conditions). Recursive partitioning. Overfitting -> pruning. CART (binary splits), ID3/C4.5 (multi-way, info gain).
W10 - APTs & Linear Regression
  • APT: Advanced (custom malware, zero-day) + Persistent (months/years undetected) + Threat (data theft/disruption).
  • 6 TIERS: I-II ($10s, exploit KNOWN vulns), III-IV ($Ms, DISCOVER unknown vulns), V-VI ($Bs, CREATE vulns in supply chain). TRAP: V-VI CREATE, not just discover.
  • KILL CHAIN: Recon -> Weaponize -> Deliver -> Exploit -> Install -> C2 -> Actions on Objectives. Break any link to stop attack.
  • CROWDSTRIKE NAMING: Bear=Russia, Chollima=DPRK, Kitten=Iran, Leopard=Pakistan, Panda=China. TRAP: Bear=Russia NOT China.
  • LINEAR REGRESSION: Y=b0+b1X+e. b0=intercept, b1=slope (care about MOST - unit change in X -> b1 change in Y). Least squares minimizes sum of squared residuals. Gauss-Markov: best unbiased linear estimator.
  • ALWAYS scatter plot first before fitting regression. Check for linearity, outliers, patterns.
W11 - Collaboration & Logistic Regression
  • COLLABORATION: Sharing/access controls, real-time editing, commenting, version control, interactive dashboards, data sync, security, mobile, ecosystem integration. Power BI: Excel publish, PowerPoint embed (live+interactive), mobile annotate. Tableau: publish to cloud, alerting, comments.
  • LOGISTIC REGRESSION: Sigmoid S-curve, probability [0,1] for binary yes/no outcomes. NOT for continuous Y (use linear). Cutoff tradeoff: lower cutoff = more catches + more false alarms.
  • CONFUSION MATRIX: TP (true positive), TN (true negative), FP (false positive = Type I), FN (false negative = Type II).
  • SENSITIVITY = TP/(TP+FN) "of real attacks, how many caught." SPECIFICITY = TN/(TN+FP) "of normal, how many correctly cleared."
  • ACCURACY = (TP+TN)/total. CAN FOOL YOU: 99% normal data -> lazy model predicts all normal -> 99% accuracy but 0% sensitivity. Sensitivity matters more in security.
  • ROC CURVE: Sensitivity (y) vs 1-Specificity (x) across all cutoffs. AUC: 0.5=coin flip (BAD), 1.0=perfect. AUC=0.5 is BAD not good.
W12 - ANOVA & Non-Parametric Alternatives
  • ANOVA: Compare 3+ group means. F=MSB/MSW (between variance / within variance). Large F -> reject H0 (groups differ). TRAP: F=between/within, NOT within/between.
  • ASSUMPTIONS: Independence, normality, equal variance (homoscedasticity). Tukey post-hoc to find WHICH groups differ after significant F.
  • TWO-WAY ANOVA: 2 factors, tests main effects + INTERACTION. Interaction = MOST IMPORTANT, read FIRST in output. Non-parallel lines in interaction plot = interaction exists.
  • MANOVA: Multiple correlated response variables. Why not multiple ANOVAs? Inflates Type I error, ignores correlations between responses.
  • NON-PARAMETRIC: Kruskal-Wallis (replaces one-way ANOVA), Friedman (replaces two-way ANOVA). Use when non-normal: zero-inflated counts, skewed times, ordinal severity, heavy tails, small n.
  • SECURITY DATA often non-normal: zero-inflated counts, skewed response times, ordinal severity ratings, heavy-tailed distributions, small incident samples.

KEY FORMULAS - COMPLETE
  • Z-TEST: Z=(Xbar-mu0)/(sigma/sqrt(n)). Critical: Z_0.05=1.645 (1-tail), Z_0.025=1.96 (2-tail at alpha=0.05).
  • VARIANCE: S^2=sum(Xi-Xbar)^2/(n-1) [sample]. sigma^2=sum(Xi-mu)^2/N [population]. Shortcut: S^2=[sum(Xi^2)-n*Xbar^2]/(n-1).
  • SD: S=sqrt(S^2). SE: sigma/sqrt(n). CV: (S/Xbar)*100%.
  • IQR FENCES: IQR=Q3-Q1. Mild: [Q1-1.5*IQR, Q3+1.5*IQR]. Extreme: [Q1-3*IQR, Q3+3*IQR].
  • CLASS RECIPE: R=max-min. m=1+3.3*log10(n). Width=R/m rounded UP.
  • EMPIRICAL: 68-95-99.7 (bell only). Chebyshev: 1-1/k^2 (any shape).
  • CORRELATION: r=Cov(X,Y)/(Sx*Sy). [-1,+1]. Median: rank=(n+1)/2. Z-score: (Xi-mean)/SD.
  • REGRESSION: Y=b0+b1X+e. b1=slope (most important). Least squares minimizes sum of squared residuals.
  • ANOVA: F=MSB/MSW. Large F -> reject H0 (groups differ).
  • LOGISTIC: P(Y=1) = 1/(1+e^-(b0+b1X)). Sigmoid [0,1]. Sensitivity=TP/(TP+FN). Specificity=TN/(TN+FP).
PARAMETRIC vs NON-PARAMETRIC DECISION TABLE
  • 1 SAMPLE: t-test (parametric) vs Sign test (non-parametric).
  • 2 GROUPS: 2-sample t-test vs Wilcoxon rank-sum.
  • 3+ GROUPS: ANOVA vs Kruskal-Wallis. TRAP: non-normal -> Kruskal-Wallis, NOT ANOVA.
  • BLOCKED: Two-way ANOVA vs Friedman test.
  • CORRELATION: Pearson r (parametric, linear, continuous) vs Spearman rho (non-parametric, monotonic, ordinal OK).
  • DECISION: Bell-shaped, large n, continuous -> parametric. Skewed, small n, ordinal, outliers -> non-parametric.
CONFUSION MATRIX QUICK REFERENCE
  • TP: Predicted attack, WAS attack. TN: Predicted normal, WAS normal.
  • FP (Type I): Predicted attack, was NORMAL (false alarm). FN (Type II): Predicted normal, was ATTACK (missed detection).
  • Sensitivity/Recall = TP/(TP+FN) -- "of all real attacks, how many caught?"
  • Specificity = TN/(TN+FP) -- "of all normal, how many correctly identified?"
  • Accuracy = (TP+TN)/total. Misleading with imbalanced data (99% normal -> 99% accuracy with 0% sensitivity).
  • ROC/AUC: Plot sensitivity vs 1-specificity. AUC 0.5=random (BAD), 0.7-0.8=fair, 0.8-0.9=good, >0.9=excellent, 1.0=perfect.
ANOVA FAMILY COMPARISON
  • t-test: 2 groups, 1 response variable. Compares two means.
  • One-Way ANOVA: 3+ groups, 1 factor, 1 response. F=MSB/MSW. Tukey post-hoc for pairwise.
  • Two-Way ANOVA: 2 factors, 1 response. Tests main effects + INTERACTION (read first). Non-parallel lines = interaction.
  • MANOVA: 1+ factors, 2+ correlated responses. Avoids inflated Type I from multiple ANOVAs.
  • NON-PARAMETRIC: Kruskal-Wallis (1-way), Friedman (2-way blocked). For non-normal security data.

EXAM TRAPS - FINAL SPECIFIC
  • 1. Sensitivity vs Specificity: sensitivity=TP/(TP+FN) catches attacks. Specificity=TN/(TN+FP) clears normals. Don't swap.
  • 2. AUC=0.5 is BAD (random coin flip), NOT good. AUC=1.0 is perfect.
  • 3. ANOVA F=MSB/MSW (between/within), NOT within/between. Large F = reject.
  • 4. Two-way ANOVA: read INTERACTION first. Non-parallel lines = interaction exists.
  • 5. Non-normal data -> Kruskal-Wallis, NOT regular ANOVA. Security data is often non-normal.
  • 6. Binary outcome (yes/no) -> logistic regression, NOT linear. Linear is for continuous Y.
  • 7. APT Tiers V-VI CREATE vulnerabilities (supply chain), not just discover them.
  • 8. CrowdStrike Bear=RUSSIA. Panda=China. Kitten=Iran. Don't mix up.
  • 9. "Accept H0" is WRONG. Say "fail to reject H0." Never proven, just insufficient evidence.
  • 10. Accuracy misleading with imbalanced data. 99% normal -> lazy model 99% accurate, 0% sensitivity.
  • 11. n-1 for SAMPLE variance (Bessel). N for population. Type I=false alarm. Type II=missed detection.
  • 12. Gestalt: Enclosure is STRONGEST, not proximity. Use borders/shading for key groupings.
  • 13. Correlation != causation. r only measures LINEAR relationships. Non-linear can have r near 0.
  • 14. Two-sided p-value: DOUBLE the one-tail probability. p=2*P(Z>=|z|). Forgetting to double = wrong.
  • 15. Sign test: discard TIES, count only pluses. R~Binomial(n,0.5) where n excludes ties.
HYPOTHESIS TESTING COMPLETE REF
  • SETUP: H0 has = sign. H1 has inequality. H1 decides WHERE rejection region. Alpha decides HOW BIG.
  • LEFT: H1: mu<mu0. Reject if Z<-Z_alpha. p=P(Z<=z).
  • RIGHT: H1: mu>mu0. Reject if Z>Z_alpha. p=P(Z>=z).
  • TWO-TAIL: H1: mu!=mu0. Reject if |Z|>Z_alpha/2. p=2*P(Z>=|z|).
  • CRITICAL Z: alpha=0.10: 1.28/1.645. alpha=0.05: 1.645/1.96. alpha=0.01: 2.33/2.576 (one/two-tail).
  • SECURITY: H0="system normal." Type I=false alarm (wastes time). Type II=missed attack (catastrophic). In security, Type II usually WORSE.
REGRESSION & CLASSIFICATION MODELS
  • LINEAR: Y=b0+b1X+e. Continuous Y. Scatter plot first. b1=slope=most important. Least squares. Gauss-Markov theorem.
  • LOGISTIC: Binary Y (0/1). Sigmoid curve [0,1]. Cutoff tradeoff. Lower cutoff -> more catches + more false alarms.
  • DECISION TREE: Root/internal/leaf/branch. Recursive partitioning. Overfitting -> pruning. CART=binary. ID3/C4.5=multi-way, info gain.
  • WHEN TO USE: Continuous outcome -> linear regression. Binary outcome -> logistic regression. Non-linear/categorical splits -> decision tree.

QUICK DECISION GUIDE
  • "Skewed data center?" -> Median. "Nominal data center?" -> Mode. "Not bell-shaped, which rule?" -> Chebyshev.
  • "p=0.03, alpha=0.05?" -> Reject H0. "p=0.08, alpha=0.05?" -> Fail to reject.
  • "IDS misses attack?" -> Type II. "IDS false alert?" -> Type I. "Binary outcome model?" -> Logistic.
  • "3+ group comparison?" -> ANOVA (normal) or Kruskal-Wallis (non-normal). "Correlation, no causation?" -> Always.
  • "AUC=0.52?" -> Terrible (near random). "99% accuracy, 0% sensitivity?" -> Useless model, imbalanced data.
  • "Non-parallel interaction plot?" -> Interaction exists, interpret BEFORE main effects.
