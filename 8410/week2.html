📈 4. Descriptive vs Inferential Statistics
DEFINITION: Descriptive statistics summarize what you have. Inferential statistics draw conclusions about a population from a sample.
TypePurposeExample
DescriptiveSummarize and describe data you collectedMean salary of surveyed employees
InferentialMake predictions/conclusions about a larger population from a sampleEstimating all employees' salary from a sample
Population vs Sample: Population = everything you want to study. Sample = the slice you actually measure. Target population (what you want) vs Sampled population (what you actually get access to).
Why can't you measure everything? The light bulb example: to test lifespan, you'd destroy every bulb. Measuring the whole population is often impossible, destructive, or too expensive.
Non-representative sample = WRONG ANSWER. If your sample doesn't reflect the population, your conclusions are invalid. Fix: use Simple Random Sampling (every item has equal chance of selection).
🎲 5. Four Sampling Designs
EXAM CRITICAL: Know the four designs and especially the difference between Stratified and Cluster sampling.
DesignHow It WorksWhen to Use
Simple RandomEvery item has equal chance of selectionPopulation is homogeneous, accessible
StratifiedDivide into groups (strata), sample a bit FROM EVERY groupPopulation has known subgroups you want represented
SystematicPick every m-th item (m = N/n)Ordered list available, no periodicity in data
ClusterDivide into groups, randomly select WHOLE groups, measure everyone in selected groupsPopulation spread geographically, costly to reach all
Critical Distinction Stratified = a little from EVERY group | Cluster = EVERYTHING from a few groups
Key Terms:
  • Sampling unit -- the individual item being selected
  • Sampling frame -- the list of all possible units to select from
  • Variable -- the characteristic you're measuring
Exam Trap: Students confuse stratified and cluster. Remember: STRATified = STRands from every layer. CLUSTer = grab a whole CLUmp.
🔢 6. Four Data Types (NOIR)
KEY IDEA: Data type determines which statistics and charts are valid. Using the wrong analysis for the wrong type = meaningless results.
TypePropertiesExamplesValid Operations
NominalCategories, no orderEye color, gender, attack typeCount, mode, bar chart
OrdinalCategories, orderedSatisfaction (low/med/high), severity ratingMedian, percentile, bar chart
IntervalNumbers, no true zeroTemperature (C/F), calendar year, IQ scoreMean, std dev, +/- but NOT ratios
RatioNumbers, true zeroHeight, weight, age, income, count of attacksAll operations including ratios
Decision Tree Number or Label? Label -> Order? No=Nominal, Yes=Ordinal. Number -> Zero=Nothing? Yes=Ratio, No=Interval
Exam Trap: Temperature in Celsius/Fahrenheit is INTERVAL, not ratio. 0 degrees C does not mean "no temperature." But temperature in Kelvin IS ratio (0K = absolute zero = no thermal energy).
Why It Matters: You can't say "80F is twice as hot as 40F" (interval). But you CAN say "80kg is twice as heavy as 40kg" (ratio). The true zero makes ratios meaningful.
📊 7. Frequency Tables & Building Classes
DEFINITION: Frequency tables organize raw data into a structured summary showing how often values occur.

Components of a Frequency Table

ColumnFormulaWhat It Tells You
Frequency (f)Count of items in categoryHow many in this group
Relative Frequencyf / totalProportion of total
PercentageRelative freq * 100Same as above, in %
Cumulative FrequencyRunning total of fHow many at or below this point

Building Classes for Numeric Data

Steps:
  1. Find Range: R = max - min
  2. Number of classes: m = 1 + 3.3 * log(n), rounded
  3. Class width: width = R / m, rounded UP
  4. Use bracket notation: [110, 117) means 110 included, 117 excluded
Example: n=50 data points, min=110, max=180.
R = 180-110 = 70. m = 1 + 3.3*log(50) = 1 + 3.3*1.699 = 6.6, round to 7.
Width = 70/7 = 10. Classes: [110,120), [120,130), ... [170,180].

1 The key difference between stratified and cluster sampling is:

Stratified is random, cluster is not
Stratified uses larger samples than cluster
Stratified samples from EVERY group; cluster takes EVERYTHING from a few randomly chosen groups
Cluster sampling requires more resources than stratified
Stratified sampling takes a proportional sample from EVERY stratum (subgroup) to ensure representation. Cluster sampling randomly selects entire groups (clusters) and measures everyone within them. Stratified = a bit from all; Cluster = all from a few.

The Sturges formula: m = 1 + 3.3 * log10(n), then round to the nearest integer. This gives a reasonable number of classes that reveals the data's shape without too many or too few bins.

Systematic sampling: pick a random start point, then select every m-th item where m = N/n. With N=1000 and n=50, m = 1000/50 = 20. You pick every 20th item from the list.
