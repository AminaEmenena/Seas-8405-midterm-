🖥 1. Endpoints & Endpoint Security Data
Definition: An endpoint is any device that connects to and communicates on a network -- desktops, laptops, servers, IoT devices, smartphones, tablets.

Endpoint Security Data Sources

  • Authentication logs -- login attempts, failed auth, session tokens
  • Access logs -- file access, privilege escalation, resource requests
  • Process logs -- running processes, parent-child relationships
  • Network connections -- outbound connections, ports, protocols
KEY IDEA: Endpoint data is the foundation of threat detection. If you cannot see what is happening on endpoints, you cannot detect attacks.

📈 4. Outlier Detection Methods
Why outliers matter in security: Anomalous behavior (outliers) often signals attacks -- unusual login times, abnormal data transfers, unexpected process executions.

Z-Score Method (Bell Curve)

Z = (X - mean) / SD. Values beyond +/-3 are considered outliers. Works best on normally distributed data.

IQR Method (Box Plot)

  • IQR = Q3 - Q1 (interquartile range)
  • Lower fence = Q1 - 1.5 * IQR
  • Upper fence = Q3 + 1.5 * IQR
  • Values outside fences = outliers
Caution: Z-score assumes bell-shaped data. For skewed distributions, the IQR method is more robust.

df.loc for Filtering

df.loc[condition] -- filter rows based on boolean condition. Example: df.loc[df['login_count'] > 100] to find high-activity users.

💡 6. Feature Engineering
KEY IDEA: Feature engineering is the "secret sauce" of machine learning. It creates new informative features from existing data and requires domain knowledge.

Security Examples

  • Login time -> "is_after_hours" boolean flag
  • Source IP + Destination IP -> "is_internal_to_external" flag
  • Timestamp -> day_of_week, hour_of_day features
  • Bytes transferred -> bytes_per_second rate feature
  • Failed logins -> rolling_failed_count over time window
Best Practice: The best features encode domain expertise. A security analyst knows that logins at 3 AM or massive data transfers to unknown IPs are suspicious -- encode that knowledge as features.
🎯 7. Measures of Center (Ch 2)
Two Questions Statistics Answers: (1) Where is the center? (2) How spread out is the data?
MeasureFormulaProperties
Mean (X-bar)sum(Xi) / nSensitive to outliers, uses every value
MedianMiddle value at rank (n+1)/2Robust to outliers, ignores extreme values
ModeMost frequent valueWorks on nominal (categorical) data
Parameter vs Statistic
Parameter = Population (Greek: mu, sigma) | Statistic = Sample (Latin: X-bar, S)

Shape from Center Relationships

"The mean chases the tail"
  • Symmetric: mean = median = mode
  • Right-skewed: mode < median < mean (tail on right, large values pull mean up)
  • Left-skewed: mean < median < mode (tail on left, small values pull mean down)
Exam Trap: Using the mean for skewed data gives a misleading picture of "typical." Use the median for skewed distributions (e.g., income data, network latencies with outliers).
📏 8. Measures of Spread (Ch 2)
MeasureFormulaNotes
Rangemax - minQuick but rough, affected by single outlier
Variance (S^2)sum(Xi - X-bar)^2 / (n-1)Units are squared (hard to interpret)
Standard Deviation (S)sqrt(S^2)Same units as data, most useful measure

Why Square the Gaps?

Plain gaps (Xi - X-bar) cancel to zero because positive and negative deviations balance out. Squaring ensures all gaps are positive and penalizes larger deviations more.

Why Divide by n-1 (not n)?

Bessel's Correction: Using n-1 corrects the bias in sample variance. Samples tend to underestimate population variance because they are closer to their own mean than to the population mean.
Exam Trap: Variance is in SQUARED UNITS. If measuring seconds, variance is in seconds-squared. SD brings it back to original units.
🔢 9. Empirical Rule & Chebyshev's Theorem
Empirical Rule (68-95-99.7) -- BELL-SHAPED DATA ONLY
Empirical Rule for Normal Distribution
| 68% | | 95% | | 99.7% | ---+---+---+---+---+---+---+--- -3 -2 -1 0 +1 +2 +3 (SDs from mean) 1 SD = 68% of data 2 SD = 95% of data 3 SD = 99.7% of data --> 3-sigma = ANOMALY DETECTION threshold
Security Application: 3-sigma rule in anomaly detection -- if a value falls beyond 3 standard deviations from the mean, flag it as potentially malicious. Only 0.3% of normal data should be that extreme.

Chebyshev's Theorem

Works for ANY shape distribution. At least (1 - 1/k^2) of data falls within k SDs of the mean. Example: k=2 -> at least 75%, k=3 -> at least 89%.

Chebyshev gives looser bounds than the Empirical Rule because it makes no assumptions about shape.

Exam Trap: Do NOT apply the Empirical Rule to non-bell-shaped (skewed, bimodal) data. For non-normal data, use Chebyshev's theorem instead.
⚠️ 10. Common Exam Traps
Watch out for these mistakes:
  1. Using mean for skewed data -- median is more appropriate when outliers or skewness exist
  2. Forgetting variance is in squared units -- always take the square root (SD) for interpretation
  3. Dividing by n for sample variance -- samples use n-1 (Bessel's correction), populations use N
  4. Applying Empirical Rule to non-bell data -- it only works for approximately normal (bell-shaped) distributions
  5. Confusing parameters and statistics -- mu/sigma = population, X-bar/S = sample
  6. Ignoring data cleaning before analysis -- garbage in, garbage out
