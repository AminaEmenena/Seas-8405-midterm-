📱 1. What is an Application & Application Security
Application: Software, hardware, or API designed for specific tasks. Includes desktop, web, mobile, and API applications. Components: frontend + backend + data storage + communication channels.
Application Security: Protecting applications from threats throughout their entire lifecycle -- design, development, deployment, and maintenance. Ensures CIA (Confidentiality, Integrity, Availability).
Lifecycle coverage is critical: Security cannot be bolted on at the end. It must be integrated from the design phase through maintenance. Each phase introduces different threat surfaces.
📊 2. Dashboard Design -- Stephen Few
Dashboard Definition (Stephen Few, Information Dashboard Design, 2006):
"A visual display of the most important information needed to achieve one or more objectives, consolidated in a single computer screen [or printed page] so it can be monitored at a glance."

Mackinlay Criterion

Two requirements for good visualization:
CriterionMeaning
ExpressivenessVisualization shows ALL and ONLY the facts in the data (nothing more, nothing less)
EffectivenessInformation is more readily perceived (uses the best visual encoding for the data type)
Key principle: Bar chart > Pie chart for comparison. Bar charts allow more accurate comparison of values because humans are better at judging length than angle.
Remember This
Mackinlay = Expressiveness (ALL and ONLY) + Effectiveness (readily perceived). Dashboard = single screen, at a glance.

📈 4. Outliers -- Impact on Mean vs Median
Outlier: A value far from the rest of the data.

Salary Example

10 employees, salaries include CEO at $1,000K (outlier):

StatisticWITH OutlierWITHOUT OutlierImpact
Mean$260K (26.0 units)$177.8K (17.78 units)Dragged up ~50% by one value!
Median17.517.0Barely budged
Mean is fragile, median is tough. One value out of ten dragged the average up ~50%, but the median barely moved.
Saying "average salary is $260K" is technically true but deeply misleading. When data is skewed, median is the appropriate measure of center.
📦 5. Boxplot & the IQR Rule
Boxplot: Draws the middle 50% as a box, marks anything unusually far out. Built from quartiles (rank-based), so it is itself outlier-resistant.

Boxplot Components

ComponentDefinition
Q1First quartile, 25th percentile
Median / Q250th percentile
Q3Third quartile, 75th percentile
IQRQ3 - Q1 (width of the middle 50%)
Boxplot Structure
Extreme Mild Mild Extreme outlier outlier outlier outlier * o |------[====|====]------| o * | Q1 Med Q3 | 3*IQR below Q1 3*IQR above Q3 1.5*IQR 1.5*IQR

IQR Fence Rule

Mild outlier fences: Q1 - 1.5*IQR and Q3 + 1.5*IQR
Extreme outlier fences: Q1 - 3*IQR and Q3 + 3*IQR
Remember This
"Step out 1.5 box-widths past each edge = mildly weird. Step out 3 = seriously weird."

What To Do With Outliers

TypeActionReasoning
Extreme (past 3*IQR)Usually discardBadly skew results
Mild (past 1.5*IQR)Investigate firstCould be error, glitch, or real rare event
When you can't delete: Down-weight or use robust statistics (median, MAD, Huber or Bisquare loss).
🛡 6. The Security Angle -- Outliers as Signals
CRITICAL DISTINCTION:
ContextOutlier MeansAction
StatisticsNoise to removeDiscard or down-weight
SecurityFrequently the whole pointINVESTIGATE before discarding
Examples of security-relevant outliers:
  • The login from another continent
  • The process spawning 10,000 connections
  • The user downloading 50GB at 3am
  • The DNS query to a never-seen-before domain
Remember This
In security, the outlier might be the attack you're hunting. Never auto-discard without investigation!
⚠️ 7. Exam Traps -- Outliers & Dashboards
Common exam mistakes to avoid:
  • Mixing up 1.5*IQR and 3*IQR fences -- 1.5 = mild, 3 = extreme
  • Reporting mean for skewed data -- Use median instead
  • Computing IQR as max - min -- That's the RANGE! IQR = Q3 - Q1
  • Auto-deleting all outliers without checking -- In security, they may be the signal
  • Confusing expressiveness with effectiveness -- Expressiveness = correct facts; Effectiveness = best encoding
Remember This
IQR = Q3 - Q1 (NOT max - min). 1.5 = mild, 3 = extreme. Skewed data -> use median. Security outliers -> investigate first.
