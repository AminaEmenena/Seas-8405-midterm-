🛡️ 1. Persistent Threats -- The Threat Landscape
CORE IDEA: Persistent threats are ongoing, recurring attack vectors that organizations face continuously. They range from common attacks to sophisticated APTs.

Common Persistent Threats

  • Phishing -- social engineering via deceptive messages
  • Ransomware -- encrypts data, demands payment
  • DDoS -- overwhelms systems with traffic
  • Botnets -- networks of compromised devices
  • Malware -- malicious software (viruses, trojans, worms)
  • MITM -- intercepts communication between two parties
  • Brute Force -- systematically tries all possible credentials
  • Insider Threats -- malicious or negligent insiders
🕵️ 2. Advanced Persistent Threats (APTs) -- Slow and Low
KEY CONCEPT: APTs are prolonged, targeted cyberattacks where attackers gain access and remain undetected for an extended period. State-sponsored or organized crime. APTs are "slow" and "low."

⚔️ 4. APT Kill Chain & Kaspersky 5-Stage Model
DEFINITION: The APT Kill Chain describes the 7-step lifecycle of an advanced persistent attack, from initial reconnaissance to final objective.

APT Kill Chain -- 7 Steps

  1. Reconnaissance -- gather information about target
  2. Weaponization -- create exploit payload
  3. Delivery -- send weapon to target (phishing, USB, malicious sites)
  4. Exploitation -- trigger vulnerability
  5. Installation -- install backdoor/malware
  6. Command & Control (C2) -- establish remote control channel
  7. Actions on Objectives -- exfiltration, destruction, or other goals
Recon --> Weaponize --> Deliver --> Exploit --> Install --> C2 --> Actions

Kaspersky 5-Stage Model

  1. Gain Access
  2. Establish Foothold
  3. Deepen Access
  4. Move Laterally
  5. Look, Learn, and Remain
Memory Aid Kill Chain: "R-W-D-E-I-C-A" -- Recon, Weapon, Deliver, Exploit, Install, C2, Act

📊 6. Linear Regression -- Fitting a Straight Line
DEFINITION: Linear regression fits a straight line through scattered data points. The model is Y = b0 + b1*X + e

Model Components

SymbolNameMeaning
YResponse / DependentWhat you predict
XPredictor / IndependentWhat you predict from
b0InterceptY when X = 0
b1SlopeChange in Y per 1-unit increase in X -- the number you care about most
eError termRandom scatter the line can't explain (assumed to average zero)
"Simple" = exactly one predictor X. "Linear" = straight line (first-order model).

Slope Interpretation

  • Positive slope -- X and Y rise together
  • Negative slope -- one rises, the other falls
  • Near-zero slope -- X tells little about Y
Security example: "Regress number of failed logins on hour of day -- a slope of 5 means each additional hour = 5 more failed logins on average."
ALWAYS SCATTER PLOT FIRST to check that the relationship looks linear before fitting a regression line.
📏 7. Least Squares & Gauss-Markov Theorem

Least Squares Method

DEFINITION: Least squares finds the best line by minimizing the total SQUARED vertical distance (residuals) from data points to the line.

Why square the distances? Same reason as variance -- prevent positive and negative errors from canceling each other out.

Residual = vertical distance from a data point to the fitted line (the prediction error for that specific point).

Gauss-Markov Theorem

KEY THEOREM: Least squares gives unbiased estimates with the smallest variance among all unbiased linear estimators. In plain English: it's the best straight-line fit without extra assumptions.

Normality Assumption

Normality is needed ONLY for confidence intervals and hypothesis tests on slope/intercept -- NOT for fitting the line itself. Normal error model: errors ~ N(0, sigma^2).
Memory Aid "Least squares = minimize SQUARED residuals. Gauss-Markov = BLUE (Best Linear Unbiased Estimator)"

🚫 9. Exam Traps -- Don't Fall For These
COMMON MISTAKES:
  • Swapping X (predictor) and Y (response) roles in regression
  • Confusing intercept (b0) with slope (b1) -- b1 is the one you care about most
  • Forgetting that least squares minimizes SQUARED distances, not absolute distances
  • Running hypothesis tests on slope without checking the normality assumption for errors
  • Thinking APT Kill Chain and Kaspersky model are the same -- they have different numbers of stages (7 vs 5)
  • Mixing up CrowdStrike animal names -- Bear is Russia, NOT China
  • Confusing Tier III-IV (discover unknown vulns) with Tier V-VI (CREATE vulns via supply chain)
