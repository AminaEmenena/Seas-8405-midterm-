W1 - Ciphers & Hashing
  • Classical ciphers: Caesar (shift, monoalpha, broken by freq analysis). Vigenere (polyalpha, repeating keyword, broken by Kasiski). Bifid (Polybius grid, combines sub+trans). Rail Fence (transposition, zigzag rows). Sub CHANGES letters, trans REARRANGES positions.
  • Shannon: Perfect secrecy = P(M|C)=P(M). OTP = ONLY perfectly secure cipher. Key must be truly random, >= msg length, used ONCE, kept secret. Impractical at scale. 5 criteria (1949): degree of secrecy, free from complexity, simple implementation, C<=P, limited error propagation - STILL VALID TODAY.
  • Symmetric vs Asymmetric: Sym = same key, fast (100-1000x), bulk data (AES/DES/3DES). Asym = key pair, slow, solves key distrib (RSA/ECC/DH). Hybrid = asym for key exchange, sym for data (TLS model). N users need N(N-1)/2 sym keys.
  • Kerckhoffs: Security in KEY, not algorithm. All modern algos public. Computational security = practical alternative to perfect secrecy: cost to break > value of info.
  • Hashing: One-way, fixed output, collision resistant, avalanche effect. SHA-256 (current), MD5 (128-bit, BROKEN), SHA-1 (160-bit, deprecated). NOT encryption - irreversible. Salting = random string before hashing, defeats rainbow tables. HMAC = keyed hash for integrity+auth (NOT confidentiality). Key stretching: PBKDF2, bcrypt (deliberately slow).
  • Data states: At rest (AES), in transit (TLS), in use (enclaves, HE). Protect all three. Block ciphers = fixed-size blocks (AES=128-bit). Stream = bit/byte at a time (RC4, ChaCha20).
  • PRNG: Uncorrelated, long period, uniform. CSPRNG required for crypto. Weak PRNG = predictable keys. Nonce = used ONCE, prevents replay.
W2 - Asymmetric Crypto & Key Exchange
  • Diffie-Hellman (1976): First pub key exchange. Shared secret = g^(ab) mod p. Based on discrete log problem. DOES NOT authenticate - vulnerable to MITM. Calc: g=2,p=19,a=6,b=3 - Y=2^6 mod 19=7, C=2^3 mod 19=8, S=8^6 mod 19=18=7^3 mod 19.
  • RSA (1977): Based on factoring N=p*q. phi(n)=(p-1)(q-1). Choose e coprime to phi, d=e^(-1) mod phi. Encrypt: C=M^e mod n. Decrypt: M=C^d mod n. Public=(n,e), Private=(n,d). Trap-door one-way function.
  • Digital signatures: Sign w/ private key, verify w/ public key. Provides auth+integrity+non-repudiation. Hash msg - encrypt hash w/ priv key = signature. Non-repudiation: signer cannot deny.
  • PKI: CA issues X.509 certificates. Chain of trust: Root CA - Intermediate CA - End entity. Revocation: CRL, OCSP. Hybrid encryption: RSA for key exchange, AES for bulk data.
  • ECC preview: Lighter than RSA. ECC-256 ~ RSA-3072. Ideal for IoT/mobile. Based on ECDLP. CAB Forum requires RSA min 3072 bits now.
  • PQC: Shor's algo breaks RSA/DH/ECC. "Harvest now, decrypt later." NIST winners: CRYSTALS-Kyber (key exchange), CRYSTALS-Dilithium (sigs), SPHINCS+ (hash-based sigs). SIKE BROKEN 2022. Migration target: 2035.
W3 - Number Theory & Math
  • Modular arithmetic: a mod n = remainder. GCD critical for RSA key gen. Euler's totient phi(n). Primes >3 are form 6k+/-1. Extended Euclidean for modular inverse.
  • Fermat's Little Theorem: a^(p-1) = 1 mod p (p prime). Chinese Remainder Theorem for solving simultaneous congruences.
  • DLP: Given g, p, g^x mod p, find x. Computationally hard = basis for DH/ElGamal. No efficient classical algorithm known.
  • Key space: n-bit key = 2^n possibilities. Brute force avg = 2^(N-1). DES: 2^56=7.2x10^16. AES-128: 2^128=3.4x10^38. N+k bits = space x 2^k.
W4 - Symmetric Encryption Deep Dive
  • Block ciphers: DES (56-bit, BROKEN 1999), 3DES (112-bit effective, deprecated, 3x slower), AES (128/192/256-bit, current standard, selected 2001).
  • AES (Rijndael): Won NIST competition (Daemen & Rijmen, Belgium). SPN structure (NOT Feistel). 128-bit block. 10/12/14 rounds for 128/192/256-bit keys. 4 ops: SubBytes (S-box, nonlinear) - ShiftRows - MixColumns (NOT in final round) - AddRoundKey. State array. GF(2^8) arithmetic.
  • Modes: ECB (deterministic, NEVER use - same block=same cipher, penguin). CBC (IV chains blocks, XOR prev). CTR (counter, parallelizable, no padding). GCM (CTR+auth tag = confidentiality+integrity, gold standard).
  • Feistel (DES) vs SPN (AES): Feistel splits block in half, same structure enc/dec. SPN = full block sub+perm, different ops enc vs dec.
  • Shannon: Confusion = complex key-ciphertext relationship (S-boxes). Diffusion = each plaintext bit affects many ciphertext bits (ShiftRows/MixColumns).
W5 - Zero Knowledge Proofs & Trust
  • ZKP: Prove knowledge without revealing secret. 3 properties: Completeness (honest prover convinces), Soundness (cheater can't fool), Zero-knowledge (verifier learns nothing). Cheating prob = 1/2^n after n rounds.
  • Ali Baba Cave: Peggy proves secret word to Victor. Interactive back-and-forth. Fiat-Shamir heuristic converts interactive to non-interactive via hash. zk-SNARKs (~100s bytes, ~10ms, trusted setup, quantum VULNERABLE). zk-STARKs (~100s KB, 50-100ms, NO trusted setup, quantum RESISTANT).
  • Trusting Trust (Thompson 1984): Turing Award. Compiler can hide backdoor. Self-replicating Trojan persists even with clean source. Trust is fundamental.
  • Why Cryptosystems Fail (Anderson): >90% failures = implementation/config errors, NOT broken math. Banking "phantom withdrawals." Need learning mechanism like aviation.
  • Why Johnny Can't Encrypt: PGP usability study. 1/3 sent secrets unencrypted. Quill pen icon miscommunicated. Crypto must be usable or people bypass it.
  • OWASP Crypto Failures (#2): 3 categories: loss of confidentiality, non-repudiation failure, failed integrity. Access control = SEPARATE category.
W6 - AES & Algorithm Selection
  • AES competition: 15 candidates, Rijndael selected. Criteria: security, performance, flexibility. S-boxes: nonlinear substitution. Key schedule: RotWord, SubWord, Rcon XOR.
  • Deep Crack: DES brute force in 22 hours (1998). Proved 56-bit keys insufficient.
  • SKIPJACK/EES: NSA cipher w/ key escrow (Clipper Chip). Matt Blaze found vulnerability. Controversial, abandoned. Can't have strong encryption AND guaranteed govt access.
  • PQC transition: NIST FIPS 203 (ML-KEM/Kyber), FIPS 204 (ML-DSA/Dilithium), FIPS 205 (SLH-DSA/SPHINCS+). Grover's halves key length: AES-128-64 (broken), AES-256-128 (safe). Need AES-256 post-quantum.
W8 - Blockchain & Digital Cash
  • Schneier digital cash: Anonymous, untraceable. 4 protocols: basic - secret splitting w/ XOR identity reveal. 6 properties (Okamoto & Ohta): Independence, Security, Privacy, Off-line, Transferability, Divisibility.
  • DigiCash: David Chaum 1989 - bankruptcy 1998. First practical digital cash attempt.
  • Byzantine Generals (Lamport): Consensus w/ malicious nodes. Solvable if >2/3 loyal (oral messages), ANY number (written/signed messages). Paxos: consensus for unreliable networks, less robust but cheaper than Byzantine.
  • Blockchain: Tamper-evident/resistant distributed ledger (NISTIR 8202). No central authority. DLT: all participants access immutable records. Smart contracts auto-execute rules.
  • Virtues: Verifiable, Immutable, Tamper-resistant, Addresses double-spend.
  • Node types: Full (stores entire chain), Publishing (full + creates blocks), Lightweight (no copy, passes to full nodes).
  • Apps: Crypto, supply chain, medical records, voting, IoT.
W9 - Elliptic Curve Cryptography
  • ECC: Discovered 1985 by Koblitz and Miller independently. Levchin Prize 2021. Equation: y^2 = x^3 + ax + b (Weierstrass). Symmetric about x-axis. Point at Infinity = identity element.
  • Validity: 4a^3 + 27b^2 != 0 (no singularities). Point Addition: line through P,Q intersects curve at 3rd point, reflect = P+Q. Point Doubling: tangent at P, intersect, reflect = 2P.
  • ECDLP: Given P and Q=kP, find k. Computationally hard - NO sub-exponential algorithm known (unlike integer factoring for RSA). This is why ECC keys can be shorter.
  • Key advantage: 160-bit ECC = 1024-bit RSA. 256-bit ECC = 3072-bit RSA. Shorter keys = speed + low power + bandwidth. Better for IoT/mobile/embedded. RSA more mature ecosystem.
  • ECDH: ECC version of DH key exchange. ECDSA: ECC digital signatures. Used in Bitcoin, TLS 1.3.
  • Finite fields/Galois fields: GF(p^n). Algebraic hierarchy: Group - Ring - Field. ECC vulnerable to quantum (like RSA). More dependent on true randomness than RSA.
W10 - Homomorphic Encryption & MPC
  • MPC: Compute function on joint inputs without revealing individual inputs. Yao's Millionaire's Protocol: who is richer w/o revealing wealth? Uses RSA.
  • Additive secret sharing: Split salary into random shares summing to original. Distribute shares across parties. Sum columns = total. Average w/o revealing individuals.
  • HE types: PHE (one op unlimited), SWHE (both ops limited depth), FHE (both ops unlimited). RSA = PHE for multiplication: E(m1)*E(m2)=E(m1*m2). NOT additive. Paillier = PHE for addition: E(m1)*E(m2)=E(m1+m2). Probabilistic (random r). Used for secure voting.
  • History: RAD 1978 "Privacy Homomorphisms" - Gentry 2009 first FHE (ideal lattices, bootstrapping). MacArthur Fellow 2014. Bootstrapping = homomorphically evaluate decryption circuit to refresh noisy ciphertext. Key breakthrough AND performance bottleneck.
  • 4 generations: 1st (ideal lattices, atrocious perf), 2nd (LWE, leveled FHE), 3rd (simpler, faster), 4th (CKKS approximate arithmetic for ML). Performance: 8x improvement/year. Bootstrapping: 1800s (2011) - 0.5s (2021).
  • Schemes: BFV = exact integer arithmetic. CKKS = approximate (ML/floating point). Paillier = additive only.
  • Apps: Cloud computing, genomics, CryptoNets (NN on encrypted data), PIR, DARPA DPRIVE. Google FHE Transpiler: converts plaintext C++ to encrypted-data code.
  • Side-channel: RevEAL paper on Microsoft SEAL. Mathematical security != implementation security.
W11 - Real World Systems (Email, SSL/TLS)
  • 5 security services: Authentication, Key Agreement, Confidentiality, Integrity, Nonrepudiation.
  • Secure email: Sender unilaterally chooses crypto (no negotiation). S/MIME needs X.509 from CA.
  • PGP: hash(MD5) - sign(RSA priv) - ZIP - encrypt(IDEA session key) - encrypt session key(RSA pub). Combines fast symmetric + secure asymmetric.
  • Sign-then-encrypt (PGP/SSL): Signature over plaintext, hides signatories. Must decrypt before authenticating. Encrypt-then-sign (IPsec): Verify before decrypting, efficient for automation. But forgery risk.
  • SSL/TLS: Auth + confidentiality + integrity. Does NOT provide nonrepudiation. SSL deprecated 2015. TLS 1.3 = current (RFC 8446). Attacks: Heartbleed/BEAST/CRIME/POODLE targeted implementations.
  • TLS protocols: Record (how to transmit) + Handshake (key agreement). ClientHello - ServerHello. Sits between application and transport layers. HTTP:80 - HTTPS:443.
  • 6 secret keys per session: 3 each direction (encryption key, HMAC key, IV). Cipher suite = key exchange algo + encryption algo + hash algo + compression.
  • Export-grade ciphers: Deliberately weak 40-bit keys (US export regulations). Digital certificates: X.509, CA trust chain, check revocation.
W12 - Wireless Crypto & Stream Ciphers
  • Wireless: STA (station/device), AP (access point, ~100m range). Open medium = eavesdrop risk. Home (single router) vs Enterprise (centralized RADIUS/TACACS+, lightweight APs). Supplicant = client device.
  • 802.1X + EAP + RADIUS: Centralized auth framework. PEAP (server certs) vs EAP-TLS (client certs).
  • RC4: Stream cipher. Key Setup (S-box) - Keystream Gen - XOR plaintext. Key reuse = fatal (XOR cancels keystream).
  • WEP: RC4 + 24-bit IV + 40-bit key. IV repeats in hours. FMS attack. No replay protection. No tamper detection. Single global key. CRC-32 linear (not crypto hash) = bit-flipping possible. Crackable in 5 hours.
  • WPA: TKIP (48-bit IV, hashed IV+key, MIC). Stepping stone, inherited WEP/RC4 weaknesses.
  • WPA2 (802.11i): AES-CCMP replaces RC4. 4-way handshake (ANonce/SNonce - PTK from PMK). PSK vs Enterprise. Cracking WPA2-PSK: capture handshake msg 2, offline dictionary - PMK - PTK - MIC match. NOT crypto broken, just weak passwords.
  • KRACK: Replays handshake - key reinstallation - nonce reuse. Targets implementation NOT AES. Affects clients. Patch to fix.
  • WPA3: SAE/Dragonfly (replaces 4-way), forward secrecy, brute force protection, individualized encryption, PMF required, 128-bit personal / 192-bit enterprise. Mandatory for Wi-Fi 6.
  • Attacks: Evil Twin (fake AP, stronger signal, intercepts traffic - VPN protects). Rogue AP (unauthorized on corp network, bypasses firewall). DoS: freq jamming, disassociation attacks.

EMAIL vs SSL/TLS vs IPsec
  • Email (PGP): Unilateral crypto (sender chooses), single message, nonrepudiation YES (signs plaintext), sign-then-encrypt.
  • SSL/TLS: Negotiated cipher suite, session-based, nonrepudiation NO, sits above transport layer, 6 keys/session, sign-then-encrypt.
  • IPsec: Negotiated, encrypts-then-signs, nonrepudiation NO, transparent to user, network layer. Verify before decrypt.
HE TYPES AT A GLANCE
  • PHE: One operation unlimited. RSA=multiply, Paillier=add, ElGamal=multiply.
  • SWHE: Both operations, limited depth.
  • FHE: Both operations, unlimited. Gentry 2009, bootstrapping.
  • Schemes: BFV=exact integers. CKKS=approximate/ML. Paillier=addition only.
WIRELESS SECURITY EVOLUTION
  • WEP: RC4+24-bit IV, broken in hours, CRC-32 (linear), FMS attack.
  • WPA: TKIP (RC4+48-bit IV+MIC), temporary fix, inherited RC4 weaknesses.
  • WPA2: AES-CCMP, 4-way handshake, PSK/Enterprise. KRACK vuln (implementation).
  • WPA3: SAE/Dragonfly, forward secrecy, 192-bit enterprise, mandatory Wi-Fi 6.
WHAT PROVIDES WHAT?
  • HMAC: Integrity YES | Auth YES | Confidentiality NO | Non-repudiation NO (shared key).
  • Digital Sigs: Integrity YES | Auth YES | Non-repudiation YES | Confidentiality NO.
  • Sym Encryption: Confidentiality YES | Integrity NO | Auth NO. Add HMAC or GCM for integrity.
  • Hashing: Integrity YES | Confidentiality NO | Auth NO (no key). Irreversible.
  • PGP: Auth+Integrity+Non-repudiation+Confidentiality (signs plaintext, then encrypts).
  • SSL/TLS: Auth+Confidentiality+Integrity. NO non-repudiation.
EXAM TRAPS & GOTCHAS
  • SSL/TLS does NOT provide nonrepudiation (PGP does)
  • RSA is multiplicatively homomorphic (NOT additively)
  • Paillier is additively homomorphic (NOT multiplicatively)
  • WPA2 KRACK targets handshake implementation, NOT AES
  • ECC 256-bit = RSA 3072-bit security (not equal bit count)
  • Bootstrapping = solution AND bottleneck for FHE
  • ECDLP has NO sub-exponential algorithm (unlike integer factoring for RSA)
  • WEP uses CRC-32 (NOT crypto hash) - bit-flipping possible
  • TLS uses 6 secret keys per session (3 per direction)
  • Sign-then-encrypt = PGP/SSL. Encrypt-then-sign = IPsec
  • Byzantine: >2/3 loyal needed (oral). Any number (written/signed)
  • 4a^3 + 27b^2 != 0 for valid elliptic curve
  • ECB = NEVER use (same block = same cipher, penguin example)
  • MixColumns NOT in AES final round
  • Quantum resistant != quantum proof (water-resistant vs waterproof)
  • Anderson: >90% failures = config/implementation, NOT broken math
  • Kindervag coined Zero Trust in 2009 (NOT 2010)
  • OWASP crypto failures: 3 categories (NOT access control)
  • Salting != Seeding (salt=unique hashes, seed=PRNG start)
  • WPA2-PSK cracking = weak passwords, NOT broken crypto
  • RC4 key reuse = fatal (XOR cancels keystream)
KEY FORMULAS & NUMBERS
  • RSA: n=pxq, phi(n)=(p-1)(q-1), exd=1 mod phi(n). Encrypt: c=m^e mod n. Decrypt: m=c^d mod n.
  • DH: Shared secret = g^(ab) mod p. Alice sends g^a mod p, Bob sends g^b mod p.
  • ECC: y^2 = x^3 + ax + b. Valid if 4a^3 + 27b^2 != 0. Q=kP (ECDLP: find k).
  • Key space: n-bit = 2^n. Brute force avg = 2^(N-1). N(N-1)/2 sym keys for N users.
  • ZKP cheating: 1/2^n after n rounds. 20 rounds ~ 1 in a million.
  • AES rounds: 128-bit=10, 192-bit=12, 256-bit=14. Grover's: effective key = bits/2.
  • Hash sizes: MD5=128-bit (broken). SHA-1=160 (deprecated). SHA-256=256 (current). Birthday attack = 2^(n/2).
  • HE perf: 8x improvement/year. Bootstrapping: 1800s (2011) - 0.5s (2021). Pinocchio: 288-byte proofs.
  • WEP: 24-bit IV + 40-bit key. WPA: 48-bit IV. WPA3: 128/192-bit.

EXCEL QUICK REFERENCE
  • Core: =MOD(a,n) modular. =POWER(base,exp). =GCD(a,b). =CODE("A")=65. =CHAR(65)="A".
  • RSA enc: =MOD(POWER(msg,e),n). Dec: =MOD(POWER(cipher,d),n). Sign: use d. Verify: use e.
  • DH: A==MOD(POWER(g,a),p). B==MOD(POWER(g,b),p). Secret==MOD(POWER(B,a),p).
  • Caesar: =CHAR(MOD(CODE(UPPER(A1))-65+key,26)+65). Vigenere: =CHAR(MOD(CODE(A1)+CODE(B1)-130,26)+65).
  • Mod inverse (brute): Col A: 1,2,3... Col B: =MOD(A1*e,phi). Find row where B=1.
